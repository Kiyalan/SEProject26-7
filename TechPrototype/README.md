# 技术原型迭代交付 | RepoPilot 代码智能知识库系统

## 一、项目简介
RepoPilot 是面向开发团队的 GitHub 仓库智能知识库与问答系统，基于 AST 语法树与 GraphRAG 增强检索技术，实现代码仓库的自动知识化与精准智能问答，帮助团队降低代码理解成本、沉淀技术知识资产。

本目录为**技术原型迭代**的全套交付成果，对应课程第二次迭代评审要求。

## 三、技术栈选型
### 后端
- 语言：Java 17
- 框架：Spring Boot
- 数据库：MySQL 8.0 / H2（开发/生产双环境支持）
- 核心能力：AST 语法解析、向量检索、GraphRAG 图检索、JWT 全链路鉴权

### 前端
- 框架：React + TypeScript
- UI 组件：Ant Design
- 工程化：OpenAPI 自动生成接口类型定义

### 工程化规范
- 容器化：Docker 统一打包部署
- 版本管理：Git 功能分支工作流 + Pull Request 交叉评审
- 数据库迁移：版本化 SQL 迁移脚本

## 五、原型快速启动说明
### 后端服务启动
1.  进入仓库根目录 `backend` 文件夹
2.  配置对应环境变量（大模型密钥、向量库地址等）
3.  执行启动命令，服务默认运行在 8080 端口
4.  访问 `http://localhost:8080/swagger-ui.html` 可查看接口文档并调试

### 前端页面启动
1.  进入仓库根目录 `frontend` 文件夹
2.  执行依赖安装命令
3.  执行开发环境启动命令，即可访问前端页面
