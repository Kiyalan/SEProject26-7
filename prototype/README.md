# 界面原型目录

本目录用于阶段一界面原型开发，当前仅包含文件夹结构，不含实现代码。

## 页面分工建议

| 目录 | 说明 |
|------|------|
| `src/pages/login` | 登录 / GitHub 授权入口 |
| `src/pages/repos` | 仓库列表 |
| `src/pages/repo-detail` | 仓库详情 |
| `src/pages/chat` | 智能问答 |
| `src/pages/issues` | Issue 列表 |
| `src/pages/issue-detail` | Issue 详情与 AI 分析 |
| `src/pages/knowledge` | 知识库视图 |
| `src/pages/settings` | 系统设置 |
| `src/layouts` | 全局布局（侧栏、顶栏） |
| `src/components` | 公共组件 |
| `docs` | Vision、用例、迭代计划等文档 |
